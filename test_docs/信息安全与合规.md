# 信息安全与合规

## 防钓鱼邮件

1. 收到要求"点击链接修改密码""紧急汇款""附件发票"的邮件，先核实发件人真实邮箱地址。
2. 鼠标悬停查看链接真实地址，与官网域名不符即为钓鱼。
3. 可疑邮件不要点击，转发到 `security@company.com` 举报。
4. 公司绝不会通过邮件索要你的域密码，任何索要密码的都是诈骗。

## U 盘与外设管理

- 公司禁用未经授权的 USB 存储设备，插入 U 盘无反应属正常安全策略。
- 确需使用 U 盘拷贝数据，走《移动存储使用申请》，IT 杀毒扫描后临时开通。
- 禁止使用私人无线网卡、随身 WiFi 接入公司内网，防止绕过安全边界。

## 信息安全红线

1. 不得将客户数据、源代码、内部文档上传到个人网盘、GitHub 或发给外部。
2. 离开工位必须锁屏（`Win + L`）。
3. 不得共享个人账号密码。
4. 违反安全红线按公司制度处理，涉及商业机密的追究法律责任。

## 软件安装规范

公司电脑禁止自行安装盗版、破解、来源不明软件。需要安装软件走以下流程：
1. 优先从"公司软件中心"自助安装（已审核通过）。
2. 软件中心没有的，提交《软件安装申请》，说明用途，IT 评估安全和授权后统一安装。
3. 涉及开发工具、数据库等有许可证的，由 IT 登记授权信息。
