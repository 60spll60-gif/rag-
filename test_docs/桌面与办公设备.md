# 桌面与办公设备

## 电脑蓝屏

1. 记录蓝屏停止代码（如 `CRITICAL_PROCESS_DIED`、`0x0000007B`）。
2. 能进系统则更新驱动、卸载最近安装的可疑软件。
3. 反复蓝屏进入安全模式（开机按 F8）做系统还原或卸载问题驱动。
4. 怀疑硬件问题用 `mdsched.exe` 检测内存，用硬盘厂商工具检测磁盘健康。
5. 数据重要且无法开机，报 IT 拆盘做数据恢复，不要自行反复通电。

## 打印机无法打印

**排查步骤**：
1. 检查打印机电源、纸张、墨粉/硒鼓，面板有无报错代码。
2. 电脑端确认默认打印机选择正确（公司打印机共享名为 `\\printserver\HP-MFP-3F`）。
3. 打印队列有卡住的任务，清空队列：停止 Print Spooler 服务，删除 `C:\Windows\System32\spool\PRINTERS` 下文件，重启服务。
4. 重新添加打印机，安装对应型号驱动。
5. 彩色打印不出来，检查是否设置了"仅黑白"或彩色墨盒耗尽。

**复印/扫描**：楼层多功能一体机扫描到邮箱，需在面板输入自己的邮箱地址，扫描文档自动发到邮箱。

## 电脑开机无显示

1. 检查显示器电源和信号线（HDMI/DP）是否松动。
2. 听主机有无报警声：连续短响多为内存问题，重新插拔内存条。
3. 换一根视频线或换一个接口测试。
4. 主机电源灯亮但风扇不转，可能电源故障，报 IT 处理。

## Outlook 收不到邮件

1. 检查是否邮箱满（公司配额 5GB），清理大邮件和已删除项。
2. 确认账户设置中服务器地址为 `mail.company.com`，端口 IMAP 993 / SMTP 587，勾选 SSL。
3. 新建 Outlook 配置文件重新添加账户。
4. 检查"垃圾邮件"过滤规则和隔离区。

## 系统卡顿 / C 盘满了

1. 清理临时文件：`%temp%`、回收站。
2. 磁盘清理工具删除系统缓存，卸载不常用软件。
3. C 盘长期不足建议重装系统或扩容 SSD，重要数据先备份到 `\\fileserver\home` 个人目录。
4. 开机自启动项过多，用任务管理器禁用不必要的启动程序。

## 数据备份策略

- 个人工作文档统一存放在文件服务器个人目录，服务器每天增量备份、每周全量备份，保留 30 天。
- 严禁只存在本地桌面或 C 盘，硬盘损坏导致的本地数据丢失无法恢复，IT 不承担责任。
- 核心业务数据由各部门负责人定期导出归档。
