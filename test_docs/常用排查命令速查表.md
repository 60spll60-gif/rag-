# 常用排查命令速查表

| 命令 | 作用 |
|------|------|
| `ipconfig /all` | 查看网卡完整配置和 IP |
| `ipconfig /release` `/renew` | 释放并重新获取 IP |
| `ping <地址>` | 测试网络连通性 |
| `tracert <地址>` | 追踪路由，定位网络中断点 |
| `nslookup <域名>` | 测试 DNS 解析 |
| `netstat -ano` | 查看端口占用和连接 |
| `tasklist` | 查看运行中的进程 |
| `sfc /scannow` | 扫描修复系统文件 |
| `gpupdate /force` | 强制刷新域策略 |
| `netsh wlan show interfaces` | 查看 WiFi 信号强度 |
| `mdsched.exe` | Windows 内存诊断 |
