# 账号与权限管理

## 域账号密码重置

- **自助重置**：登录界面按 `Ctrl+Alt+Del`，选择"更改密码"（需记得旧密码）。
- **忘记密码**：联系 IT 服务台，验证工号和身份信息后由域管理员在 Active Directory 中重置，重置后首次登录必须修改。
- 密码策略：至少 8 位，包含大小写字母+数字+特殊符号，90 天强制更换，不能与前 3 次历史密码重复。

## 新员工账号开通

新员工入职当天，HR 提交《IT 资源开通申请单》，IT 完成以下配置：
1. 在 AD 域创建账号，分配到对应部门组织单位（OU）。
2. 开通邮箱（Exchange）、OA 系统、企业微信。
3. 按部门分配文件服务器权限（研发部 `\\fileserver\rd`，财务部 `\\fileserver\fin`）。
4. 配置 VPN 权限（如需远程办公）。
5. 发放笔记本电脑并加入域。

## 离职账号处理

员工离职当天 18:00 前，IT 必须：禁用（非删除）其域账号、回收邮箱、收回所有设备、移除所有系统权限。账号保留 90 天用于审计后归档删除。

## 权限申请与审批

1. 员工需要新增系统权限时，在 OA 提交《权限申请单》，说明业务理由。
2. 直属主管审批 → 系统负责人审批 → IT 执行开通。
3. 高权限（管理员、财务、HR）需额外经信息安全负责人审批。
4. 所有权限变更留审计日志，每季度做一次权限复核（access review）。
