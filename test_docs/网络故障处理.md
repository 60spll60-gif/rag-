# 网络故障处理

## 电脑无法上网（有线网络）

**现象**：右下角网络图标显示黄色感叹号或红叉，网页打不开。

**排查步骤（由简到难）**：
1. 检查网线两端是否插紧，网口指示灯是否亮起（绿色闪烁为正常）。
2. 打开命令提示符，执行 `ipconfig /all`，看是否获取到 IP 地址。
   - 如果 IP 是 `169.254.x.x`，说明 DHCP 没拿到地址，属于 IP 分配失败。
   - 正确办公网段应为 `10.20.x.x`。
3. 手动释放并重新获取 IP：依次执行 `ipconfig /release` 然后 `ipconfig /renew`。
4. 用 `ping 10.20.0.1` 测试能否 ping 通网关。ping 不通说明是二层链路问题，检查交换机端口或网线。
5. 能 ping 通网关但打不开网页，用 `nslookup www.baidu.com` 测试 DNS。DNS 失败则把网卡 DNS 改为 `114.114.114.114` 或公司内网 DNS `10.20.0.53`。

**常见根因**：交换机端口 down、网线水晶头接触不良、DHCP 地址池耗尽、网卡被禁用。

## WiFi 连不上或频繁掉线

**排查步骤**：
1. 确认连接的是公司 SSID：办公区 `Corp-Office`，研发区 `Corp-RnD`，访客区 `Corp-Guest`。
2. 忘记网络后重新输入域账号密码连接（WiFi 采用 802.1X 认证，用的是 Windows 登录的域账号，不是独立密码）。
3. 频繁掉线优先排查信号强度，`netsh wlan show interfaces` 查看 Signal 百分比，低于 60% 建议换到近处 AP。
4. 同一区域多人掉线，报网络组检查 AP 或无线控制器（AC）是否异常。

**访客 WiFi**：`Corp-Guest` 连接后浏览器会自动跳转到认证页，输入手机号获取短信验证码上网，访客网络无法访问内网资源。

## 网速慢 / 卡顿

1. 用 `speedtest` 测速，对比公司标准带宽。
2. 检查是否有程序占用带宽（如云盘同步、Windows 更新、视频会议）。
3. 有线用户检查网卡是否协商在千兆（`1000/1000 Mbps`），若显示 100M 说明网线或端口有问题，更换超五类以上网线。
