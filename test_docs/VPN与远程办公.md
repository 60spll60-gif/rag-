# VPN 与远程办公

## 如何连接公司 VPN

**客户端**：EasyConnect / GlobalProtect（按 IT 邮件通知的版本安装）。

**步骤**：
1. 服务器地址填写 `vpn.company.com`。
2. 用户名用域账号（如 `zhangsan`），密码为域密码。
3. 首次登录会要求绑定设备，需在手机端安装"擎云信"扫码认证（MFA 双因子）。
4. 连接成功后，状态栏图标变绿，即可访问内网系统（OA、ERP、文件服务器）。

**注意**：VPN 账号连续 5 次密码错误会锁定 30 分钟，联系 IT 解锁。

## VPN 连上了但访问不了内网

1. 检查是否开启了"分流"模式，部分客户端默认只代理内网网段，确认目标 IP 在内网路由表中。
2. 执行 `route print` 看是否有到 `10.20.0.0/16` 的路由。
3. 本地防火墙或第三方安全软件（360、火绒）可能拦截，临时退出后重试。
4. 客户端版本过旧，卸载后重装最新版。

## 远程办公安全要求

1. 远程办公必须通过 VPN，禁止直接暴露内网服务到公网。
2. VPN 会话空闲 30 分钟自动断开，需重新认证。
3. 禁止在公共 WiFi 下处理敏感数据，如需办公请开启手机热点。
